A fast drop-in replacement for csv-reader 1.0.0 — reads broken CSV files exactly as csv-reader does, only faster. Single-pass parser with bulk fast paths for clean rows and a careful slow path for quoted and broken rows.

## Run it

```sh
node main.ts
```

Reads `/input/cases.json`, writes `/output/answers.json`.
